# 🎨 一拍即玩 SnapPaint III

**SnapPaint** 是一款純前端的 HTML5 網頁填色遊戲，將您拍攝或上傳的照片，自動轉換為基於 **12-bit RGB (4096色)** 的數字拼圖。透過尋找對應的顏色編號並逐格填滿，享受解謎的樂趣，最終重現出獨特的像素藝術作品！

## ✨ 核心特色

- 📷 **即影即玩**：支援直接調用相機拍照或從相簿上傳圖片。
- 🔬 **全解析度支援**：提供 **6 個解析度階梯**（1x 完整、1/2x、1/4x、1/8x、1/16x、1/32x）。1x 模式下，一張 1920×1080 的照片會被切成 **2,073,600 個方格**，挑戰極致耐心與眼力。
- 🎨 **12-bit 顏色量化**：自動將千萬色照片濃縮至最多 4096 種顏色，並映射為清晰的順序編號（1, 2, 3...）。
- 🧩 **智能泛洪填色 (Flood Fill)**：點擊任一同色區域，整個連通區域會**瞬間整片填滿**，讓百萬格的拼圖也能玩得動。
- 🔍 **無極縮放與視口裁切**：專為高難度設計的視圖控制系統 — 編號只在夠大時才顯示（culling 渲染），確保流暢不卡頓。
- 💡 **自動接續選色**：當某一種顏色全部填完，會自動切換到下一個尚未完成的顏色，避免中斷心流。
- ✨ **所選顏色高亮脈動**：目前使用的顏色會有黃色脈動光暈，其他顏色變淡，讓您永遠不會迷失在數千個色塊中。
- ⚠️ **雙重確認重置**：重置按鈕需要連點兩次才會生效，3 秒內不確認會自動取消，防止意外清掉進度。
- ⏱️ **計時與進度追蹤**：HUD 上有圓環進度條與計時器，記錄您的解謎效率。
- 🏆 **本地作品畫廊**：完成拼圖後可一鍵儲存，每幅作品都能獨立縮放瀏覽、下載、刪除。
- 📲 **PWA / APK 雙版本**：網頁版可加到主畫面，Android 使用者也有打包好的 APK 安裝檔。

## ⚙️ 技術細節

- **純前端架構**：零後端依賴，單一 `index.html` 檔案即可離線運行，無需任何建置工具。
- **Canvas API 渲染引擎**：
  - 使用離屏 Canvas 進行圖片降採樣與顏色提取
  - 採用 **viewport culling**（視口裁切），只渲染畫面中看得見的方格與編號
  - **Scanline Flood Fill** 掃描線填充演算法，高效處理百萬格的同色區域填充
- **Typed Array 優化**：使用 `Uint16Array` / `Uint32Array` / `Uint8Array` 儲存色鍵、計數與填色狀態，大幅降低記憶體開銷與 GC 壓力。
- **智慧文字渲染**：利用 `measureText` 即時計算數字的像素寬度，根據編號長度（1-4 位）動態縮放字體，並套用圓角描邊 (`lineJoin = 'round'`)。
- **響應式視口 (Viewport)**：採用 `100dvh` 與 Flexbox 彈性佈局，完美適配帶有動態網址列的現代手機瀏覽器。
- **本地持久化**：使用 `localStorage` 儲存 Base64 編碼的完成作品，支援單項刪除與空間不足時自動淘汰。
