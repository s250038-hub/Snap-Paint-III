# 🎨 一拍即玩 SnapPaint

**SnapPaint** 是一款純前端的 HTML5 網頁填色遊戲。它能將您上傳或拍攝的照片，自動轉換為基於 **12-bit RGB (4096色)** 的數字拼圖。透過尋找對應的顏色編號並逐格填滿，您不僅能享受解謎的樂趣，還能最終重現出一幅獨特的像素藝術作品！

## ✨ 核心特色

- 📷 **即影即玩**：支援直接調用相機拍照或從相簿上傳圖片。
- 🎚️ **動態難度系統**：根據圖片原始比例，提供 4 種基於面積縮放的難度（1/1, 1/4, 1/16, 1/64），最高難度挑戰極致眼力。
- 🎨 **12-bit 顏色量化**：自動將千萬色照片濃縮至最多 4096 種顏色，並映射為清晰的順序編號（1, 2, 3...），用完的顏色會自動從調色板消失。
- 🖌️ **流暢的畫筆體驗**：支援長按拖拽連續填色，無需反覆點擊，大幅提升填色效率。
- 🔍 **無極縮放與平移**：專為高難度設計的視圖控制系統，確保微小格子也能精準點擊。
- 🌓 **智慧灰階與高對比**：未填色區域顯示原圖灰階輪廓，編號自動適配黑/白雙色描邊，確保在任何背景下都清晰可讀且不超界。
- 🏆 **本地作品畫廊**：完成拼圖後可一鍵儲存至瀏覽器本地，隨時回顧您的藝術創作。

## 🎮 操作指南

### 💻 PC 端 (滑鼠與鍵盤)
| 動作 | 操作方式 |
| :--- | :--- |
| **選擇顏色** | 點擊底部圓形調色板，或在輸入框輸入編號後點擊「選擇」。 |
| **單格填色** | 滑鼠**左鍵**點擊格子。 |
| **連續填色 (畫筆)** | 按住滑鼠**左鍵**並拖動，滑過目標格子即可連續填色。 |
| **平移畫布** | 按住滑鼠**右鍵**並拖動 (已自動禁用瀏覽器右鍵選單)。 |
| **縮放畫布** | 滾動滑鼠**滾輪** (最高支援 10 倍放大)。 |
| **重置視圖** | 滑鼠**雙擊**畫布區域，畫面會瞬間回到中心並恢復原始大小。 |

### 📱 行動裝置 (觸控螢幕)
| 動作 | 操作方式 |
| :--- | :--- |
| **選擇顏色** | 點擊底部圓形調色板，或輸入編號。 |
| **單格填色** | **單指**輕觸格子。 |
| **連續填色 (畫筆)** | **單指**按住並滑動，塗抹經過的格子。 |
| **平移與縮放** | **雙指**捏合縮放 / **雙指**按住拖動平移畫布。 |
| **重置視圖** | **雙指**快速輕觸兩下 (Double Tap)。 |

## ⚙️ 技術細節

- **純前端架構**：零後端依賴，單一 `index.html` 檔案即可離線運行，無需任何建置工具。
- **Canvas API 渲染**：使用離屏 Canvas (Offscreen Canvas) 進行圖片降採樣與顏色提取，確保高效能與色彩準確度。
- **智慧文字渲染**：利用 `measureText` 即時計算數字的像素寬度，動態縮放字體並套用圓角描邊 (`lineJoin = 'round'`)，徹底解決文字溢出或糊成一團的問題。
- **響應式視口 (Viewport)**：採用 `100dvh` 與 Flexbox 彈性佈局，完美適配帶有動態網址列的現代手機瀏覽器。
- **本地持久化**：使用 `localStorage` 儲存 Base64 編碼的完成作品，實現輕量級畫廊功能。

## 🚀 如何開始

1. 下載或複製本專案中的 `index.html` 檔案。
2. 使用任何現代網頁瀏覽器 (Chrome, Safari, Edge, Firefox) 直接雙擊開啟該檔案。
3. 允許瀏覽器存取相機/相簿權限（若使用拍照功能），即可開始遊玩！

*(💡 提示：為獲得最佳體驗，建議將網頁加入書籤或「加入到主畫面」以全螢幕模式運行。)*
